# Una pequeña historia de amor

Etapas 1 y 2: dos personajes SVG con encuentro, flor y abrazo. Sin dependencias.

Servir esta carpeta por HTTP y abrir index.html. Pulsa Comenzar para ver la historia de 12 segundos; también puedes seleccionar los movimientos básicos. Puedes elegir una pista local; no se envía a ningún servidor. La sincronización coreográfica se desarrollará en Etapa 3.

Edita config.js para cambiar la dedicatoria o establecer una ruta relativa a un audio autorizado. La canción comercial no forma parte del repositorio.

Preparado para GitHub Pages desde la raíz de la rama principal; despliegue todavía no realizado. Consulta PROGRESO.md e INSTRUCCIONES_CONTINUIDAD.md.

Pruebas sin dependencias: `node tests/story.test.cjs` y `node tests/controls.test.cjs`. Revisión visual en Safari pendiente.
